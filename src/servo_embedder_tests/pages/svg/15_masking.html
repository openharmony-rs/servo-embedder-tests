SVG - Masking Effects

1. Luminance & Opacity Masking (White=Visible, Black=Hidden)

Tests <mask> luminance mapping where white pixels reveal content, shades of grey apply transparency, and black completely hides content.

2. Gradient Masking (Smooth Alpha Dissolve)

Tests gradient-based smooth alpha transitions inside a <mask> container to create feathering effects.

3. Text Cutout Masking (English, Chinese, Arabic)

Tests inverted text cutout masking where black multi-language <text> nodes punch holes through a solid white mask frame.

4. Mask Coordinate Units (objectBoundingBox vs userSpaceOnUse)

Tests proportional scaling of mask geometries across different element dimensions using maskContentUnits="objectBoundingBox".

5. mask-type (alpha vs luminance)

Tests mask-type. Left: alpha keys off the alpha channel only, so an opaque red circle reveals fully. Right: luminance keys off color luminance, so the same red circle is dim (≈21%) while the white circle stays bright.

6. maskUnits="userSpaceOnUse" (fixed region)

Tests maskUnits="userSpaceOnUse", where the mask region is fixed in user coordinates (left half, x=0…175). The left rect is inside the region and shows; the right rect is outside and is fully hidden.

7. Mask region x/y/width/height (objectBoundingBox)

Tests explicit mask region x="0.25" y="0.25" width="0.5" height="0.5". The mask content is clipped to the center quarter of the element, so only that quarter of the green rect is revealed over the gray backing rect.

8. Mask on <text>

Tests a raster mask applied to a <text> leaf, rasterized through its glyph outlines. The text fades left-to-right as the luminance mask's gradient falls to black.

9. Nested mask on <mask> content

Tests a <mask> whose content is itself masked (nested mask). The black circle inside the outer mask is cut to its left half by the inner mask, so the orange rect is hidden only under that half-circle — the right half of the circle region stays visible.

10. Masked group with transformed child (single mask)

Tests a masked <g> containing a transform-carrying child. The group is rasterized as one unit and masked once, so the overlapping red/green rects composite to a uniform green under the 50% mask with no darkening seam at the overlap.

11. Mask on <image> (raster image)

Tests a luminance <mask> applied to a raster <image> (data-URI PNG). Expected: only a circular spotlight of the image is revealed. Known limitation: this engine renders the image unmasked, because <image> pixels live only in a WebRender ImageKey with no CPU-side buffer to multiply the mask into — the fix is CPU image readback, or a WebRender image-mask clip on quads.
